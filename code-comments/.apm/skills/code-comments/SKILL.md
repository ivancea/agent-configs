# Code comments

## Comments describe the current code

Write a comment for someone reading the code as it is now. Do not explain the previous implementation, the edit you just made, or why an alternative was rejected.

If a sentence only makes sense when the reader already knows what the code used to do, delete it or rewrite it so it stands on its own.
